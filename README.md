# SRE-Website

Official Web Platform for **SRE Fitness Academy (Sports Sciences & Biomechanics Institute)**.

## 🚀 Overview
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + High-contrast Dual Themes (Dark & Light)
- **Interactive UI:** 3D Physics tilt cards, Parallax background animations, Dynamic course syllabi modals
- **Key Modules:**
  - Trainer Verification System (with Google Sheets CSV integration)
  - Fitness Calculators (1RM, BMR/TDEE, HR Zones, FFMI, EMI Calculator)
  - Virtual Lab & Biomechanics Floor Tour
  - Academic Prospectus & Downloadable Kinesiology Whitepapers
  - Admissions Inquiry & 1-Click WhatsApp Counselor Desk

## 🛠️ Development & Deployment
```bash
# Install dependencies
npm install

# Run local development server
npm run dev

# Build for production
npm run build
```

## 🔄 Quick Update Tool
Double-click `push-to-github.bat` on Windows to commit and push changes directly to GitHub, triggering auto-deploy on Vercel.
